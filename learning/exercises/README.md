# Your exercise answers

This folder is **your workspace**. Course repos stay unchanged; you work here.

| Course     | Files              | Run your answers                    |
|------------|--------------------|-------------------------------------|
| python     | `python/day_XX.py` | `python3 learn.py python N --run-exercise` |
| javascript | `javascript/day_XX.js` | `python3 learn.py javascript N --run-exercise` |
| react      | `react/day_XX.md`  | Notes + checklist; code in boilerplate apps |

## Daily workflow

1. `python3 learn.py python 1 --open` — read the lesson
2. `python3 learn.py python 1 --exercise` — open your answer file
3. Fill in Level 1 and Level 2 sections
4. `python3 learn.py python 1 --run-exercise` — run **your** file

Replace `python` with `javascript` or `react` as you progress.
