# Level 1 — Ages 5 to 7

Eight worksheets on counting, number bonds, adding and taking away. Use real objects (beads, coins, blocks) beside every page.

:::parent How to use these worksheets
- One worksheet a day is plenty; half a worksheet is fine too.
- Read the questions aloud for children who are still learning to read.
- Let the child draw dots, use fingers or count objects. That is not cheating; it is learning.
- Check answers together using the answer key at the end of each level. Praise effort and method.
:::

Eight worksheets on tables, money, sharing, mental addition and the first shortcuts.

:::parent Tips for Level 2
- Ask the child to say **how** they got each answer.
- For tables, practise a few facts daily rather than a whole table at once.
- Use real coins and notes for the money worksheets.
