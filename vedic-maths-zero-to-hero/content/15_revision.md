### 58.7 Algebraic identities

:::formula Identities
(a + b)² = a² + 2ab + b² · (a − b)² = a² − 2ab + b² · a² − b² = (a + b)(a − b)
(a + b)³ = a³ + 3a²b + 3ab² + b³ · (a − b)³ = a³ − 3a²b + 3ab² − b³
a³ + b³ = (a + b)(a² − ab + b²) · a³ − b³ = (a − b)(a² + ab + b²)
(a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)
(x + a)(x + b) = x² + (a + b)x + ab
Quadratic roots: x = (−b ± √(b² − 4ac)) / 2a
:::

### 58.8 Aptitude formulas

:::formula Percentages, profit and interest
Successive change: a + b + ab/100 · r% more → r/(100 + r) less
SP = CP(100 + P%)/100 · SP = MP(100 − D%)/100 · Profit % on CP
SI = PRT/100 · A = P(1 + R/100)ᵀ · 2-year CI − SI = P(R/100)²
:::

:::formula Ratio, averages and mixtures
Share = total × part/(sum of parts) · Weighted average = Σnᵢaᵢ/Σnᵢ
Alligation: cheaper : dearer = (dearer − mean) : (mean − cheaper)
Replacement: x(1 − y/x)ⁿ · Partnership: capital × time
:::

:::formula Time, work, speed
Work: total = LCM; outlets negative · M₁D₁H₁/W₁ = M₂D₂H₂/W₂
D = S × T · km/h × 5/18 = m/s · Average speed (equal distances) = 2ab/(a + b)
Trains: add lengths; relative speed adds (opposite) or subtracts (same)
Boats: boat = (down + up)/2, stream = (down − up)/2
:::

:::formula Counting and probability
ⁿPᵣ = n!/(n − r)! · ⁿCᵣ = n!/(r!(n − r)!) · P(not A) = 1 − P(A)
P(A or B) = P(A) + P(B) − P(A and B)
:::

:::formula Mensuration
Rectangle lb, 2(l + b) · Triangle ½bh, Heron √(s(s−a)(s−b)(s−c)) · Circle πr², 2πr
Cuboid lbh, 2(lb + bh + hl) · Cube a³, 6a² · Cylinder πr²h, 2πrh · Cone ⅓πr²h, πrl · Sphere 4/3 πr³, 4πr²
:::

:::formula Calendar
Odd days: ordinary year 1, leap year 2; 100 yrs 5, 200 yrs 3, 300 yrs 1, 400 yrs 0
Months: Jan 3, Feb 0/1, Mar 3, Apr 2, May 3, Jun 2, Jul 3, Aug 3, Sep 2, Oct 3, Nov 2, Dec 3

## Chapter 59: Common Mistakes, Exam-Day Strategy and Checklists

### 59.1 Twenty common mistakes

| # | Mistake | Correct idea |
|---|---|---|
| 1 | Forgetting to carry in Urdhva | carry everything except one digit from each column |
| 2 | Wrong number of digits on the right in Nikhilam | right part has as many digits as the base has zeros |
| 3 | Sign errors with mixed deviations | one above and one below → right part is negative |
| 4 | "All from 9" applied to the last digit | the last non-zero digit is from 10 |
| 5 | Ekanyunena with unequal digit counts | pad with zeros or use a base method |
| 6 | Squares ending in 5 for 3-digit numbers | n(n + 1) still works: 115² → 11 × 12 \| 25 |
| 7 | Treating a² + b² as (a + b)² | remember 2ab |
| 8 | Profit % on SP | profit % is on CP |
| 9 | Averaging speeds | use 2ab/(a + b) |
| 10 | Adding successive percentages | a + b + ab/100 |
| 11 | Wrong units (km/h with metres) | convert first |
| 12 | Leap-year rule for 1900 | 1900 is not a leap year |
| 13 | Digit-sum check "proves" an answer | it only rejects wrong answers |
| 14 | Over-rounding in approximation | round to the nearest easy number |
| 15 | Missing the overlap in "or" probability | subtract P(A and B) |
| 16 | Remainder taken as negative | add the divisor to make it positive |
| 17 | −(a − b) written as −a − b | −(a − b) = −a + b |
| 18 | Misreading the scale in DI | read title, units and scale first |
| 19 | Using a shortcut that does not fit | check the condition (same tens? near a base?) |
| 20 | Spending too long on one question | use the two-pass method |

### 59.2 Exam-day strategy

1. Sleep well the night before. A tired brain is slower than any shortcut can make up for.
2. Warm up for 5 minutes: a few squares, tables and percentages.
3. Read each question fully before calculating.
4. First pass: easy questions only. Second pass: marked questions.
5. Estimate before choosing; check the units digit and the size of the answer.
6. With negative marking, avoid pure guesses. Guess only after eliminating at least two options.
